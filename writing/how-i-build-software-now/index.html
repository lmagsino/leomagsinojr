The shift

The bottleneck moved, so I moved

For most of my career, the unit of work was the keystroke. You thought, you typed, you tested, you shipped. AI pair tools chipped at that from 2022 onward, but the job stayed the same shape: an engineer with a very fast autocomplete.

Somewhere over the last year and a half, the shape changed. The agents got good enough to take a ticket from description to pull request on their own. Anthropic’s 2026 Agentic Coding Trends report describes the same thing I was living: being a software engineer increasingly means orchestrating agents that write code — evaluating their output, giving direction — rather than typing the code yourself. The industry phrase is agentic engineering. My phrase is simpler: I stopped being the typist and became the line manager.

But here’s the part that took me longest to accept: when agents write the code, writing code stops being the constraint. Deciding what to build, reviewing what was built, and verifying it actually works become the constraint. Any hour I spend has to go where the bottleneck now is.

That realisation produced the two systems I now run every working day: AI Light Factory on the build side, and Three-Pass Review on the review side. Both are open source. What follows is how they fit together into one working day.
